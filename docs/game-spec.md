# 已确认的游戏规则

来源：111 (3).docx 与用户在本聊天中的后续确认。后续确认覆盖文档冲突。

## 材料与探索

共23种可收集材料。删除鸡蛋、肥皂、散粉，保留护肤品。花草一项，枯枝落叶一项。冻肉是不可收集场景互动。八种不同材料必须收齐，不可重复，不可替换，全部拖入锅后才能制药。宫殿长廊、天空之城每收集一件风险加1，其他场景为0；重复查看或进场景不加风险。风险大于5立即触发提前失败。椅子不增加风险。84互动顺序为毒药、椅子、再次毒药。

## 结局优先级

1. 风险大于5：药还没喝呢！探索时立即触发。
2. 巨龙对话大于等于3次：双向奔赴。必须完成制药，不喝药，妈妈陪孩子出去玩。
3. 任意材料有毒：抵达新世界。
4. 出泡材料至少三种：咕噜咕噜。
5. 八种全可食，好吃至少四种：大厨也是大魔法师。
6. 八种全可食：软绵绵的小猪。
7. 剩余无毒组合：屁股火辣的小英雄，包括不能吃但无毒、出泡不足三种的组合。

不使用难吃比例。仅结局五、六揭示现实身份；普通结局提示再试一次。女巫毒药、护肤品、香水均有毒。牙膏等属性按原案作为虚构标签保存，不作现实食用指导。

## 首版实现

使用无依赖静态 HTML CSS JavaScript，确保可以直接打开 index.html。统一数据、纯规则、界面分离。触屏和鼠标通过 Pointer Events 拖放，逐个投入八份材料。制药动画包括搅拌、上升气泡、液面涌动；减少动态效果偏好会关闭循环动画。

前三次巨龙对话不同，第四次及之后采用理解后的陪伴对白。前三段分别展示严厉阻拦、担忧原因、愿意陪伴。文案由开发者拟稿，后续由用户修改。

苹果衍生材料、灵感深度已删除。不增加战斗系统：服药后直接按策划进入结局叙事。所有素材本地，不联网、不登录、不需要游戏服务器。尚未加入刷新恢复、安装型离线缓存或自动发布。

## 后续界面补充要求

覆盖优先级改为人物立绘高于文本框，文本框高于背景。旁白不显示玩家立绘或 NPC，文字使用完整文本框宽度。背包满八格后继续点击收集弹出明确的背包已满提示，不改变持有材料或内部风险。隐藏画面中的场景标题、周目状态及存档列表中的场景和周目描述，保留必要的导航入口名称。场景物品取消悬停、焦点框选及名称提示，背包取消物品选择描边，物品详情仍须点击后查看。


## 初始提示 存档删除及直接拖放

首次进入制药所时自动播放旁白提示，说明点击紫色大锅和搅拌木棍制药、点击黑色门洞离开，并说明材料拖入锅口。提示沿用逐字播放和点击推进规则，记录为已访问，不在返回时重复播放。

存档列表增加逐项删除按钮，三个手动槽及自动存档可独立删除，删除后立即持久保存。删除自动存档不会被关闭设置等界面操作立刻重建，实际推进游戏时恢复自动保存。周目完成记录独立保留。

制药改为从底部背包直接拖动物品至锅口，支持鼠标和触屏 Pointer Events。有效松手逐一投入并保存进度；锅外松手、取消、失焦及重复投入均不增加材料。移除先选择材料再点击投入的步骤。键盘可聚焦材料按 Enter 直接投入。八种不同材料全部入锅的门槛保持不变。


## 物品交互的魔法闪光

场景交互点添加小型星光，以不同节奏缓慢明暗变化，按场景使用暖金、冰蓝、淡粉或浅绿。未收集材料、大锅、门洞及恶龙互动点显示星光，已收集材料不再闪烁。闪光不显示物品名称或框选范围，也不修改附件原图。对白或弹窗期间隐藏星光；减少动态效果设置下改为静态星光。
