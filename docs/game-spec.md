# 已确认的游戏规则

来源：111 (3).docx 与用户在本聊天中的后续确认。后续确认覆盖文档冲突。

## 材料与探索

共23种可收集材料。删除鸡蛋、肥皂、散粉，保留护肤品。花草一项，枯枝落叶一项。冻肉是不可收集场景互动。八种不同材料必须收齐，不可重复，不可替换，全部拖入锅后才能制药。宫殿长廊、天空之城每收集一件风险加1，其他场景为0；重复查看或进场景不加风险。风险大于5立即触发提前失败。椅子已删除。第四周目获得小木梯后可收集女巫毒药。

## 结局优先级

1. 风险大于5：药还没喝呢！探索时立即触发。
2. 巨龙对话大于等于3次：双向奔赴。必须完成制药，不喝药，妈妈陪孩子出去玩。
3. 配方包含女巫毒药：喝药中毒真结局。
4. 出泡材料至少三种：咕噜咕噜。
5. 八种全可食，好吃至少四种：大厨也是大魔法师。
6. 八种全可食：软绵绵的小猪。
7. 剩余无毒组合：屁股火辣的小英雄，包括不能吃但无毒、出泡不足三种的组合。

不使用难吃比例。仅结局五、六揭示现实身份；普通结局提示再试一次。只有女巫毒药触发中毒结局；护肤品、香水为不能吃、无毒。牙膏等属性按原案作为虚构标签保存，不作现实食用指导。

## 首版实现

使用无依赖静态 HTML CSS JavaScript，确保可以直接打开 index.html。统一数据、纯规则、界面分离。触屏和鼠标通过 Pointer Events 拖放，逐个投入八份材料。制药动画包括搅拌、上升气泡、液面涌动；减少动态效果偏好会关闭循环动画。

前三次巨龙对话不同，第四次及之后采用理解后的陪伴对白。前三段分别展示严厉阻拦、担忧原因、愿意陪伴。文案由开发者拟稿，后续由用户修改。

苹果衍生材料、灵感深度已删除。不增加战斗系统：服药后直接按策划进入结局叙事。所有素材本地，不联网、不登录、不需要游戏服务器。尚未加入刷新恢复、安装型离线缓存或自动发布。
