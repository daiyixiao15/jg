# 一锅小小的魔法

TapTap 聚光灯比赛 H5 单机游戏流程原型。在原有 jg 仓库开发，使用占位图形、文字与简单动画。

## 打开游戏

直接用 PC 浏览器打开根目录 index.html。手机可以通过静态文件托管地址访问；游戏运行不需要账号、接口、数据库或后端，全部资源位于仓库内。此原型没有安装型离线缓存，也不保存刷新后的进度。

开发时也可在仓库启动任意静态文件服务。静态文件服务只用于提供文件，不参与游戏规则。

## 怎么玩

1. 点击场景入口，点击物品查看并收集八种不同材料。
2. 宫殿长廊、天空之城每拿一件加1风险；超过5立即提前失败。
3. 女巫毒药：先点击毒药，再点击椅子，最后再次点击毒药收集。
4. 客厅每次与巨龙交谈推进不同对话，三次之后理解它的心意。
5. 收满八种后去大锅。点击底部瓶子选中，再按住瓶子拖入大锅；每种都需要单独投入。键盘使用者选中瓶子后可按 Enter 投入。
6. 全部入锅后点击开始制药，搅拌并播放涌现动画。对话达到三次时放下药去找巨龙，否则喝药进入对应结局。

## 一起修改

- src/data.js：全部材料、幻想名称、标签、场景描述、巨龙对话、结局文案。真实物品名称仅保存在数据，不在普通结局界面揭示。
- src/rules.js：收集限制、风险、入锅门槛和结局优先级。
- src/game.js：界面和交互。
- src/style.css：PC、手机布局及动画。
- docs/game-spec.md：已确认规则和原型范围。
- tests/rules.test.cjs：规则验证，可用 Node 执行 node tests/rules.test.cjs。

没有网络请求、在线字体或外部资源。无需安装依赖或构建。文案是首版草稿，可直接修改 data.js。没有添加成就、图鉴、灵感或新玩法系统。
