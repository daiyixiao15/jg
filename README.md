# 一锅小小的魔法

按最新《需更改 (1).docx》和用户后续确认更新。当前规则以本次新增说明为准。

## 打开游戏

直接用浏览器打开 index.html，无需安装依赖或构建。

## 操作

1. 黑色启动界面选择开始，输入名字，点击屏幕翻阅故事书。游戏会记住上次使用的名字，再次开始时可选择继续使用或换一个名字；取消更名不改变记忆。引子结束后进入制药所，自动显示一次提示，说明点击大锅制药、点击黑色门洞前往下一处。
2. 点击黑色门洞到中央公园。中央公园只有制药所、泡泡王国、天空之城、梦幻森林、宫殿长廊五个入口。
3. 天空之城右下角箭头进入冰雪塔楼下层；点击下层黄白色门洞进入上层。宫殿长廊右下角箭头进入恶龙盘踞之地。左上角返回沿路径回到上一个场景。
4. 各场景仅首次进入显示环境介绍。对白逐字输出，点击补全文字，再次点击下一句；书本引子每次点击直接翻页。播放时所有背景交互均锁定，空格、Enter 也可推进对白。对话框透明度为60%（黑色背景不透明度40%），覆盖优先级为玩家立绘高于文本框、文本框高于对话 NPC 立绘、NPC 高于背景；旁白只显示文本框，不显示人物立绘。场景标题和周目次数不展示，导航入口保留必要名称。物品悬停不显示框选范围、名称或属性，点击后查看介绍。
5. 背包在右上角开关，打开后画面底部出现一排八格。点击物品查看介绍，丢弃会实际移除物品；已经入锅的该物品也会移除，需重新收集八份后制药。材料属性及风险数值不显示。背包填满后再点击收集会提示不可继续收集。
6. 收齐八种不同材料，返回制药所点击紫色大锅和木棍。直接按住背包里的物品，用鼠标或触屏拖到锅口松开即可投入；无需先选择或点击投入按钮。全部投入后开始制药。拖到锅外或取消拖动不会投入材料；键盘使用者可聚焦材料后按 Enter 直接投入。
7. 制药完成会询问是否前往恶龙场景。确认后到达该场景并选择喝下药水，触发配方结局。没有结局 CG 时使用黑屏和对白。
8. 每完成一次结局，下一次开始为下一周目。恶龙剧情随周目改变，同周目反复点击不升级剧情。第五周目及以后，完成恶龙对话可触发双向奔赴真结局。

## 存读档

右上角设置内有存档和读档，支持三个手动存档位置，存档会覆盖所选位置。自动存档独立保存当前进度，包括尚未读完的对白。启动界面继续先打开存档列表，选择后再恢复。存档列表中已保存的数据各有删除按钮，可独立删除某个手动存档或自动存档。删除自动存档后，不会因关闭设置立刻重新生成，继续实际游玩时恢复自动保存。存档及已完成周目保存在当前浏览器，清除浏览器数据后会丢失。旧版自动存档可迁移。制药中恢复会视为搅拌完成。

## 素材与试运行范围

附件原图直接复制使用，未修改图片。新附件替换玩家立绘，并加入恶龙立绘、恶龙睡眠场景、无恶龙对话背景及冰塔物品图。森林、长廊和冰塔上层已使用附件原图；未提供的物品介绍沿用原稿。椅子已删除。第四周目恶龙完整对话获得小木梯，持有梯子后可在泡泡王国点击、查看并收集女巫毒药。只有女巫毒药进入配方才触发中毒真结局，护肤品、香水改为不能吃、无毒。

## 检查与文件

运行 node tests/rules.test.cjs 和 node tests/game.test.cjs。前者验证配方与风险内部规则，后者验证引子、对话锁定、背包、场景路径、存读档及周目剧情。

src/data.js 保存材料与结局，src/story.js 保存新引子和周目对白，src/rules.js 保存内部规则，src/game.js 保存交互，src/style.css 保存布局，assets 保存附件素材。

## 2026年10月13日原图与新增玩法

本轮使用附件本地原始 PNG，不使用聊天缩略图或 Word 中的参考图片。补齐冰塔上层、梦幻森林、宫殿长廊，替换新的恶龙睡眠背景、无恶龙背景及玩家立绘。图片本身保持原尺寸、原字节；显示时通过 SVG 视窗隐藏透明边距，保持比例。src/assets.js 记录来源文件、尺寸、透明边距和 SHA256。

- 毛绒绒怪任务：两份妙脆角是独立任务道具，各占一格，不能入锅，交付后消失。暂缺介绍写为“待补充”。完成后自动获得毛绒绒怪的美食。奖励丢在地上可再次拾取，背包满时可选择丢弃背包物品。首次拒绝和再次接受分别有对白。
- 小公主：首次分支对白、三件赠礼、按空位选择、暂存、重新领取。只有在长廊当面丢弃她赠送的物品才累计次数；首次固定对白，第二次随机对白，第三次本周目永久关闭全部赠礼入口。换周目重置，已经持有的宝物仍可制药。
- 傻不拉鸡：笑或绷住，再选择抢帽子或请求，最后决定是否归还；两条结尾均获得小破帽子，归还分支解锁对应成就。完成后可再次交谈。角色原图直接使用，不重绘背景。
- 冰冰糖只能摇晃互动，不能收集；三次解锁“请你吃糖！”。下层冰草草是单独点击彩蛋，上层仍是正常材料。
- 成就入口在启动界面。结局、互动、丢弃二十次、全材料和全结局记录跨存档累计，同一浏览器内保存。清除浏览器数据会清除成就。
- 小猪、大丑怪及恶龙笑脸使用提供的原图；其他未提供的变身形态和 CG 继续用黑屏/文字。中毒结局增加门、三秒白屏和现实揭示；陪伴结局确认与大龙一起出发。结束显示“完”，可直接开启下一周目或存档，下一周目跳过翻书引子。

文案修改入口：src/npc-story.js 为 NPC 分支，src/ending-story.js 为结局对白，src/achievements.js 为成就名称说明，src/quests.js 为任务道具说明。原有 src/data.js、src/story.js 仍分别保存材料、结局基础数据和引子、周目对白。

尚待补充：多周目旧“我赶时间，我先走了！”后续、小公主彩蛋承诺及妙脆角介绍仍为“待补充”。电视机暂用简易占位图。毛绒绒怪第三张立绘未提供，按文档暂用第二张。巨大怪兽、高级仙灵、泡泡龙和医院等结局 CG 未提供，按文档使用黑屏/文字。任务奖励独立物品图未提供，背包使用占位图。
