# 一锅小小的魔法

根据“需更改.docx”调整的试运行版，保留23种材料、八种材料制药及原有结局判定。

## 打开与操作

直接在浏览器打开 index.html，无需安装或构建。

1. 在启动界面选择“开始”，输入玩家名字；“继续”读取当前浏览器的存档。
2. 首次进入制药所，点击黑色门洞到中央公园，点击紫色锅和木棍制药。
3. 中央公园有五个目的地。冰雪塔楼入口在天空之城的彩虹云梯，巨龙在中央公园门边。
4. 点击背景中的物品打开介绍，选择收集或丢弃。右上角背包可反复展开、收起。
5. 女巫毒药需要先查看，再借助泡泡王国下方小椅子，最后再次查看收集。
6. 收齐八种回制药所，打开背包，逐一选择材料并点击大锅投入，全部投入后开始制药。
7. 对话逐字显示，点击游戏画面或按空格、Enter 补全文字，再次点击推进下一段。不会自动跳到下一段。

进度自动保存到本地浏览器，也可用右上角“存档”“读档”。仅有一个存档槽，开始新冒险会覆盖。清理浏览器数据会清除存档。制药中读取存档视为完成搅拌。结束游戏回到停止界面，浏览器标签页可自行关闭。

## 试运行范围

画面固定4:3，四张背景和玩家立绘均使用附件原文件，未修改源图片。风险值只用于内部判定。梦幻森林、宫殿长廊及巨龙场景暂用占位画面；缺少物品介绍沿用原稿。泡泡王国图片中没有椅子，底部补充椅子交互区。冰雪塔楼上层材料继续使用原有设计与临时位置。
